## 第一章 · 设计决策：为什么是"暖调皮肤 × 宜家骨架"

### 1.1 决策背景

RSDP 现有前端（Vue 3 + Naive UI 管理端）暴露四类典型问题：

1. **色彩过饱和**：`#2453FC` 品牌蓝大面积渐变铺底、`#FF0000` 纯红价格，视觉刺激强，与家居品类应有的"温度感"冲突；
2. **字体栈缺陷**：`--rsdp-font-display: 'Gloock','Georgia',serif` 为英文衬线字体，中文标题实际回退到系统默认字体，中英文气质断裂；
3. **缺少用户端心智**：现有界面是"管理端思维"（vxe-table 表格、维度导航），而消费者购买家具的心智是"看图、逛空间、比价格"；
4. **首页写死**：Banner 轮播 + 维度导航硬编码在 HomeView，运营无法配置。

### 1.2 为什么是宜家骨架

对 ikea.cn 实测拆解（首页 3 屏 + 沙发 PLP 2 屏截图存证）后确认，宜家官网的信息架构是家居电商的最优解之一：

- **三轴导航**（商品类目 × 房间空间 × 系列）同时服务两种购买心智——"我要买一张沙发"与"我要布置客厅"；
- **首页 = CMS 区块流**，运营可配置、大促可换肤，与 RSDP 已有的 `platform_banner / platform_case / platform_content / platform_custom_dict` CMS 表设计天然同构；
- **PLP 的商品卡信息密度设计**（标签 + 变体 + 价格三段式 + 评分 + 双视图）是行业教科书；
- **AI 户型搭配**作为 RSDP 差异化能力，可以无缝嵌入宜家的"房间空间轴"——空间轴的智能化延伸。

### 1.3 为什么是暖调皮肤而非宜家蓝黄

| 维度 | 宜家蓝黄（#0058AB / #FFDB00） | 暖调家居馆（style-a） |
|---|---|---|
| 品牌联想 | 强宜家联想，易被认作"山寨" | 独立品牌人格 |
| 与产品图融合 | 冷白底 + 高饱和撞色，对米色/木色产品图不友好 | 米白/暖杏底与暖调产品图天然融合 |
| 国内用户偏好 | 北欧冷淡风受众相对窄 | 奶油风/原木风是国内家居主流审美 |
| 管理端久用 | 高饱和蓝黄长时间盯屏易疲劳 | 低饱和暖调更舒适 |

**结论**：骨架全抄宜家（信息架构、排列方式、交互模式），皮肤用暖调（色彩、字体、圆角），即"宜家的里子，自己的面子"。

### 1.4 双主题并存策略

- **用户端官网**（本设计文档）：style-a 暖调家居馆 × 宜家式排列，面向消费者，Nuxt 3 SSR；
- **管理端工作台**：style-b 现代极简工作台（已确认），面向内部运营，沿用现有 Vue 3 工程换肤；
- 两端通过**深棕（#6F4A2E）/ 赭石（#C2622B）**元素保持品牌一家人的感觉。

## 第二章 · 设计系统（Design Tokens 完整规范）

### 2.1 色彩系统

#### 2.1.1 基础色板

| Token | 色值 | 用途 | 使用比例建议 |
|---|---|---|---|
| `--bg` | `#FAF7F2` | 页面主背景（米白） | 60% |
| `--card` | `#FFFFFF` | 卡片/面板背景 | 25% |
| `--suppl` | `#F3EADF` | 补充色（暖杏）：图片占位底、促销价底、搜索框底、强调区块底 | 10% |
| `--ink` | `#2B2118` | 主文字（深墨棕） | — |
| `--ink2` | `#9C8B78` | 次要文字（灰驼）：描述、meta、placeholder | — |
| `--line` | `#E8DFD2` | 分割线、边框 | — |

#### 2.1.2 品牌/功能色

| Token | 色值 | 用途 |
|---|---|---|
| `--accent` | `#8B5E3C` | 主品牌色（中棕）：主按钮、链接悬停、激活态、新品标签 |
| `--accent-deep` | `#6F4A2E` | 深品牌色（深棕）：logo、标题强调、深色区块底（CTA/Footer/工具条） |
| `--terra` | `#C2622B` | 功能强调色（赭石）：促销、"优惠活动"导航项、促销价文字、"即将下架"标签、错误/警示 |

#### 2.1.3 色彩使用规则（重要）

1. **赭石 = 促销专属**：`--terra` 只出现在与"钱/优惠"相关的位置（促销价、优惠活动导航、大减价卡、即将下架标签），不得用于普通按钮或装饰，保持用户对"赭石=便宜"的条件反射；
2. **深棕 = 结构专属**：`--accent-deep` 用于页面"骨架两端"（顶部工具条 + CTA + Footer）和 logo，中间内容区不出现大面积深棕；
3. **促销价 vs 原价**：促销价 = 暖杏底（`--suppl`）胶囊 + 赭石字 + 划线原价；正常价 = 深棕字无底。绝不用纯红 `#FF0000`；
4. **图片是唯一的高饱和来源**：页面所有色块保持低饱和，让产品图成为视觉焦点（宜家"白盒子"原则的暖调版）。

### 2.2 字体系统

| Token | 值 | 用途 |
|---|---|---|
| `--font-serif` | `'Noto Serif SC','Songti SC','STSong','Georgia',serif` | 展示字体：页面标题、区块标题、商品名、价格整数、Footer 栏目标题 |
| `--font-body` | `'Helvetica Neue','PingFang SC','Microsoft YaHei',sans-serif` | 正文字体：导航、按钮、描述、表格、meta 信息 |

**字号阶梯**：

| 级别 | 字号 | 字重 | 字体 | 用于 |
|---|---|---|---|---|
| Display | 42px / 34px | 700 | serif | Hero 标题 / PLP 类目标题 |
| H2 | 24~27px | 700 | serif | 区块标题（必逛好物/新品上架…） |
| H3 | 16~17px | 600 | serif | 商品名、卡片标题 |
| Body | 14~15px | 400 | body | 正文、描述 |
| Meta | 12~13px | 400 | body | 规格、评分、面包屑、工具条 |
| Price-Int | 25~26px | 700 | serif | 价格整数部分 |

**字距规则**：中文标题/按钮 `letter-spacing: 1~3px`；英文 kicker（如 `WHOLE-HOME SEASON`）`letter-spacing: 6px` 全大写。

**修复要点**：现有 tokens.css 的 `'Gloock'` 必须替换为 `'Noto Serif SC'` 开头的中文字体栈，否则中文标题永远回退失效。

### 2.3 圆角、阴影与间距

| 类型 | 值 | 用于 |
|---|---|---|
| `--radius` | 16px | 卡片、区块容器 |
| 大圆角 | 24px | Hero 容器、CTA 容器 |
| 胶囊 | 999px | 按钮、搜索框、筛选药丸、标签、房间名胶囊、价格促销底 |
| 卡片阴影 | `0 4px 18px rgba(90,64,42,.07)` | 静态 |
| 卡片悬停阴影 | `0 12px 32px rgba(90,64,42,.13)` + `translateY(-4px)` | hover |
| Hero 阴影 | `0 8px 30px rgba(90,64,42,.08)` | — |

**间距系统**：区块上下间距 56px（首页）/ 页面最大宽度 1320px / 页面左右 padding 40px / 卡片网格 gap 20~24px。

### 2.4 交互反馈

| 元素 | 默认 | 悬停 |
|---|---|---|
| 主按钮 btn-a | `--accent` 底白字 | `--accent-deep` 底 |
| 次按钮 btn-b | 透明底 + `--accent` 边 + 深棕字 | 暖杏底 |
| 导航项 | 底边 2px 透明 | 底边 `--accent` + 深棕字 |
| 商品卡 | 静态阴影 | 上浮 4px + 深阴影 |
| 房间入口图 | 1x | `scale(1.05)`，250ms |
| 筛选药丸 | 白底灰边 | `--accent` 边 + 深棕字；选中 = `--accent` 底白字 |

## 第三章 · 首页 index.html 区块级详解

首页共 11 个区块（0~10），自上而下排列。每个区块对应一个 CMS 区块类型，运营可在管理端配置显隐与内容。

### 区块 0 · 顶部工具条

- **内容**：左侧「📍 中山 · 佛山 ｜ 预约到店体验」；右侧「对公业务 / 设计服务 / 下载APP」
- **样式**：`--accent-deep` 深棕底、`#EFE3D5` 字、12px、字距 1px
- **数据**：静态文案，可挂 `platform_custom_dict`（类型 `topbar_link`）
- **宜家出处**：ikea.cn 顶部条

### 区块 1 · Header（吸顶）

- **结构**：衬线 logo（RSDP + 瑞时家居）｜ 居中胶囊搜索框（max-width 540px，暖杏底，占位文案"搜索商品、系列或空间灵感，试试「三人沙发」"）｜ 右侧图标组（门店 / 登录注册 / 心愿单 / 购物车）
- **样式**：`rgba(250,247,242,.94)` + `backdrop-filter: blur(8px)` 半透吸顶，`top:0, z-index:50`
- **交互**：搜索框聚焦时建议出联想下拉（后续接 `/api/v1/public/search/suggest`）
- **宜家出处**：ikea.cn Header（logo 左、搜索中大、图标右）

### 区块 2 · 主导航（三轴模型）

| 导航项 | 类型 | 落点 |
|---|---|---|
| 所有商品 ▾ | 类目轴（Mega Menu） | PLP（products.html） |
| 房间 ▾ | 空间轴（Mega Menu） | 房间聚合页（后续） |
| 优惠活动 | 促销入口，赭石色 | 活动聚合页 |
| 设计和服务 | 服务页 | 预约设计表单 |
| 家居灵感 | 内容轴 | 灵感列表 |
| 新品 | 商品轴 | PLP（新品筛选） |
| **AI 户型搭配** | **RSDP 差异化入口** | AI 搭配流程页（后续） |

- **样式**：15px/600/字距 1px，底边 2px 透明 → hover 底边 `--accent`；「优惠活动」恒为 `--terra`
- **Mega Menu 内容建议**：「所有商品」= category_dict 两级树（SF 沙发/TB 茶几/FC 柜类/FS 座椅/DT 餐桌/BD 床/LT 灯具/OF 办公）；「房间」= scene_dict（客厅/卧室/书房/餐厅/办公）
- **宜家出处**：ikea.cn 导航 8 项；AI 户型搭配为第 7 项差异化入口

### 区块 3 · Hero（首屏）

- **结构**：style-a 分割式大卡（圆角 24px、白底、柔和阴影），左文右图 1.05fr:1fr
- **文案**：kicker「整家搭配季 · WHOLE-HOME SEASON」（13px/字距6px/中棕）→ 衬线大标题「让**客厅**，先一步变成家」（42px，客厅二字深棕）→ 描述（AI 搭配价值主张）→ 双按钮（主：立即体验 AI 搭配；次：浏览客厅灵感）
- **右侧图**：`assets/hero-living.png` 暖调客厅场景图
- **CMS 映射**：`platform_banner`（主 Banner 位），大促时可整体换肤为促销版（宜家同款运营手法）
- **后续扩展**：接 `floor_plan_analysis` 后，主按钮直接进入"上传户型图"流程

### 区块 4 · 必逛好物（3 色块卡）

- **内容**：大减价（赭石底白字）/ 当季新品（深棕底暖杏字）/ 更低价格（暖杏底深墨字）
- **样式**：min-height 160px、底部对齐文案、hover 上浮 3px、serif 22px 标题
- **CMS 映射**：`platform_content`（区块类型 `trio_cards`，3 条记录：标题/副文案/配色/跳转）
- **宜家出处**：必逛好物 3 卡（大减价/当季新品/更低价格）1:1 对应

### 区块 5 · 服务卡（4 卡）

- **内容**：🚚 送货服务（珠三角 48h）/ 🔧 安装服务 / ↩️ 退换保障（30 天）/ 📐 免费设计（AI + 设计师 1v1）
- **样式**：白卡 + 静态阴影，图标 24px 中棕
- **宜家出处**：宜家服务卡（送货/组装/退换）+ RSDP 第 4 卡「免费设计」为差异化

### 区块 6 · 从房间开始探索

- **内容**：5 个空间入口（客厅/卧室/书房/餐厅/办公空间），图片 + 左下白色胶囊标签
- **交互**：hover 图片 `scale(1.05)`；点击进入该空间的聚合页（后续接"房间页"）
- **数据**：scene_dict；每个空间配一张代表场景图（`platform_case` 或字典扩展字段）
- **宜家出处**：ikea.cn「从房间开始探索」10 房间；RSDP 先上 5 个与 scene_dict 对齐

### 区块 7 · 新品上架（商品横排 × 宜家 PLP 卡）

- **区块头**：衬线标题「新品上架」+ 右侧「商品图/场景图」切换 + 「查看全部新品 →」（跳 PLP）
- **商品卡结构**（与 PLP 完全同款，见第四章）：
  - 图区 4:3：左上标签（热卖=墨底 / 新品=中棕底 / 即将下架=赭石底）、左下变体胶囊（+N 种颜色/尺寸）、hover 可切场景图
  - 信息区：serif 商品名 → 风格 · 尺寸 meta → **价格三段式** → 评分
- **数据**：RSPU 按创建时间倒序取 4~8 条，主图经 `image_assets.is_primary` join
- **宜家出处**：ikea.cn 首页新品区 + PLP 商品卡规格

### 区块 8 · 家居灵感（瀑布）

- **布局**：CSS Grid `2fr 1fr 1fr`，第一格纵向跨 2 行（1 大 + 4 小）
- **内容**：场景图 + 左下白色胶囊标题（如「18㎡ 小客厅的三人位解法」）
- **数据**：`platform_case`（案例）或 `platform_content`（区块类型 `inspiration`）
- **后续**：点击进灵感详情页，页内挂"图中同款"商品链接（宜家" shop the look"模式）

### 区块 9 · 留资 CTA

- **样式**：`--accent-deep` 深棕大圆角（24px）色块，居中：serif 30px 标题「不知道从何开始？」→ 副文案 → 白底深棕字胶囊按钮「免费获取搭配方案」
- **数据**：提交后写入 `platform_lead`（注意：**迁移编号应为 V34**，不是 V31，需与 V1__init_db.sql、reset_db.sql 三处同步）
- **RSDP 专属**：宜家无此区块，为 RSDP 线索收集核心入口

### 区块 10 · Footer

- **样式**：`#241A12` 深棕黑底、5 列网格（品牌 2fr + 购物/服务/关于/联系各 1fr）、栏目标题 serif 15px 暖杏色、底部版权行
- **内容**：品牌语「为每一个家，提供买得起的好设计与好品质」+ 备案号 + 隐私政策/Cookie 设置
- **宜家出处**：ikea.cn 深色多列 Footer

## 第四章 · 商品列表页 products.html（PLP）详解

PLP 是"宜家排列方式"的精髓页，也是与 RSPU 产品库数据结合最深的页面。

### 4.1 页面结构（自上而下）

1. **面包屑**：首页 ／ 所有商品 ／ 客厅家具 ／ 沙发（12px/灰驼/字距1px，可点击逐级返回）
2. **类目头**：serif 34px 大标题「沙发」+ 右侧「86 件商品」计数（14px 灰驼）
3. **类目文案**：一段 14px 灰驼 SEO 文案（"一张好沙发，是客厅的底色……"）——利于搜索引擎收录，对应 `platform_content` 或 category_dict 扩展 description 字段
4. **筛选药丸条（吸顶，`top:117px` 位于 Header 之下）**：
   - 药丸：价格排序▾（选中态）/ 座位数▾ / 商品分类▾ / 颜色▾ / 尺寸▾ / 材质▾ / + 更多筛选
   - 右侧：商品对比开关 + 商品图/场景图切换
5. **已选筛选 chips**：三人位 × / 布艺 × / ¥1,000 - ¥5,000 ×（暖杏底深棕字，点 × 移除并刷新列表）
6. **商品网格**：4 列 × N 行，gap 24px
7. **加载更多**：白底描边胶囊按钮 + 「已显示 8 / 86 件商品 · 商品对比（0/3）」计数
8. Footer（同首页）

### 4.2 筛选维度与后端字段映射

| 筛选项 | 数据来源 | 说明 |
|---|---|---|
| 价格排序 | RSPU 参考价 / RSKU 报价聚合 | 升序/降序切换 |
| 座位数 | `rspu_variant.dimensions` JSONB 的 seat_count 或宽度的分档推断 | 单人/双人/三人/L 型 |
| 商品分类 | `category_dict`（dict_type=category，dict_type+dict_code 复合键） | SF/TB/FC/FS…两级 |
| 颜色 | RSPU 颜色字段/字典 | 建议建 color_dict |
| 尺寸 | `rspu_variant.dimensions`（宽/深/高 mm） | 分档：如沙发宽 <1800 / 1800~2200 / >2200 |
| 材质 | RSPU 材质字段 | 布艺/真皮/科技布/实木 |

### 4.3 商品卡规格（与首页新品卡同款）

```
┌─────────────────────┐
│ [热卖][新品]    [⊕] │  ← 左上标签胶囊；右上对比按钮（对比开关开启时显示）
│                     │
│   商品图（4:3）      │  ← 默认白底商品图；切换"场景图"后整列替换
│  [+3 种颜色]        │  ← 左下变体胶囊
├─────────────────────┤
│ 云朵三人位布艺沙发    │  ← serif 16px/600
│ 现代简约 · 2200×950×880│ ← meta 12px 灰驼（风格 · 尺寸）
│ ¥ 4,680 .00  ¥5,200 │  ← 促销：暖杏底胶囊+赭石字+划线原价
│ ★★★★☆ 4.6 (128)    │  ← 评分 12px
└─────────────────────┘
```

**价格三段式规则**（宜家标志性排版）：
- `¥` 符号：12px/700，顶部对齐（margin-top 4px）
- 整数：serif 25px/700，行高 1
- 小数 `.00`：12px/700
- 促销态：整体套暖杏底胶囊 + 赭石字；正常态：深棕字无底

### 4.4 已实现的交互（原型内 JS）

1. **商品图/场景图双视图切换**：点击切换按钮，整列商品的 `plain/scene` 两张图互换显示——对应后端 `image_assets` 的主图（is_primary）+ 场景图（asset_type=scene）双资产模型；
2. **商品对比开关**：开启后每张卡右上角出现 ⊕，底部计数"商品对比（0/3）"，最多 3 件进入对比（后续出对比抽屉/页面）。

### 4.5 待实现（开发期）

- 筛选面板展开（药丸点击出下拉/抽屉）、筛选条件与 URL query 同步（利于分享与 SEO）；
- 加载更多改无限滚动或分页器；
- 对比结果浮层（参数表格：尺寸/材质/价格/评分）；
- 空态与加载骨架屏。

## 第六章 · 与后端的数据对接映射

| 前端区块/组件 | 后端接口（建议） | 数据表 | 备注 |
|---|---|---|---|
| Hero Banner | `GET /api/v1/public/home` | platform_banner | 已有 |
| 必逛好物/服务卡/灵感 | `GET /api/v1/public/content/{code}` | platform_content | 已有，区块类型 trio_cards/service_cards/inspiration |

| 新品上架/PLP 列表 | `GET /api/v1/public/products?category=&sort=&page=` | RSPU + rspu_variant + image_assets（is_primary join） | 筛选参数对应第四章映射表 |
| 场景图 | 随商品返回 `sceneImageUrl` | image_assets（asset_type=scene） | 双视图切换的数据基础 |
| 留资提交 | `POST /api/v1/public/leads` | **platform_lead（V34 迁移）** | ⚠️ 文档中 V31 需改 V34，三处同步 |

**安全边界**：以上均为 `/api/v1/public/**` 门面，SecurityConfig 现有 `.anyRequest().permitAll()` 兜底模式下加白名单即可；绝不暴露 RSKU 工厂报价（AES 加密字段不解密出库到用户端）。

**状态值纪律**：review_status 用中文值（已确认/待复核/存疑），status 用小写（active）——前后端保持一致。

## 第七章 · 管理端 style-b 主题约束

管理端维持 style-b「现代极简工作台」（已确认），不在本次改动范围，但需遵守两条品牌一致性约束：

1. **品牌呼应**：管理端保留赭石 `#C2622B` 作为功能强调色（style-b 原生即有），与用户端促销赭石一致；
2. **价格组件共用**：`<PriceText>` 同一实现，管理端以默认态（深棕字）使用，不出现促销态。

现有 web/ 工程换肤仅需替换 `web/src/styles/tokens.css` 变量值与字体栈，组件不动。

## 第八章 · 响应式、无障碍与性能

### 8.1 响应式断点（原型当前为桌面版，落地时需补）

| 断点 | 适配 |
|---|---|
| ≥1200px | 当前设计（4 列商品、5 列房间） |
| 768~1199px | 商品 3 列、房间 3 列、Hero 维持分割 |
| <768px | 商品 2 列、房间 2 列横滑、Hero 改上下结构（图上文下）、导航收进抽屉、筛选药丸横滑 |

### 8.2 无障碍

- 促销信息不只依赖颜色：促销价同时有"暖杏底 + 划线原价"双信号；
- 图片 alt 必填（商品名 + 规格）；对比开关、视图切换有 `aria-pressed`；
- 文字对比度：`--ink` on `--bg` ≈ 12.6:1，`--ink2` on `--bg` ≈ 3.9:1（仅用于大字/次要文本，正文字勿用 ink2 小号）。

### 8.3 性能

- 图片：商品图统一 WebP、4:3 裁剪，PLP 列表懒加载；Hero 图预加载（LCP 优化）；
- Nuxt 3 SSR 首屏直出 + 区块级 `Lazy` 水合；CMS 区块接口加 CDN 缓存（对齐宜家 Cloudflare 策略）。
