# 商品列表（SPU）页面复现需求文档

> 本文档是给 Kimi Code 的执行指令。目标：在本项目管理端复现参考系统的「商品列表」页面布局。
> 参考页面（真实线上环境，可登录查看）：https://admin.rooom.vip/mall/product/spu （账号 admin / admin123456）
> 要求：不需要做到像素级一模一样，但页面结构、区域划分、组件形态、视觉风格要高度相似。
> 明确排除：**不做库存管理相关的业务功能**（警戒库存逻辑、库存编辑、库存预警等一律不做）。

---

## 0. 执行前置要求（Kimi Code 必读）

1. 先阅读项目 `web/src/views/` 下已有的页面（如 `SchemeListView.vue`、`UserSettingsView.vue`）和布局组件，确认项目使用的组件库（大概率是 Element Plus / Element UI）与现有布局框架。
2. **复用项目已有的整体布局**（侧边栏、顶栏、页签栏）。如果项目已有布局框架，本任务只新增页面内容区和路由/菜单，不要重写布局。如果没有布局框架，再按下文第 2 节实现。
3. 接口未就绪时，先用 mock 数据把页面完整跑通；API 请求层单独封装在 `api/` 目录，方便后续替换为真实接口。

### 2.1 左侧侧边栏（仅当项目无布局时才需要实现）

- 深色背景（参考色 `#304156`），宽约 200~210px。
- 顶部：系统 logo 图 + 系统名称（白色粗体）。
- 菜单为树形可展开结构，当前页面「商品列表」所在路径自动展开，当前菜单项整行蓝色高亮（背景 `#409EFF` 或主题主色，白色文字）。
- 参考菜单结构：

```
首页
后台管理
基础设施
会员中心
商城系统
  ├─ 商城首页
  └─ 商品中心

       ├─ 商品分类
       ├─ 商品品牌
       ├─ 商品属性
       └─ 工厂评分

```

### 2.2 顶栏

- 左侧：侧边栏折叠按钮（汉堡图标）+ 面包屑 `商城系统 / 商品中心 / 商品列表`（最后一级灰色不可点）。
- 右侧图标区：全屏、搜索、字号、语言切换、消息铃铛、用户头像 + 用户名。

### 2.3 页签栏（多页签）

- 每个打开的页面一个页签；当前页页签为主色白字（带刷新小图标），其余为白底灰字。
- 右侧：收起全部、刷新当前页、页签操作九宫格图标。
- 若项目已有页签组件则直接复用，不要重复实现。

## 3. ① 搜索卡片（页面顶部白色卡片）

两行布局，表单项 label 右对齐，控件宽度一致（约 220px），行间距均匀。

**第一行（4 个表单项）：**

| 顺序 | Label | 组件 | 占位提示 |
|---|---|---|---|
| 1 | 商品名称 | 输入框 | 请输入商品名称 |
| 2 | 供应商编码 | 输入框 | 请输入供应商编码 |
| 3 | SPU 编码 | 输入框 | 请输入SPU 编码 |
| 4 | 商品分类 | 下拉选择（可做成级联/树选择） | 请选择商品分类 |

**第二行（2 个表单项 + 3 个按钮）：**

| 顺序 | 内容 | 组件 | 说明 |
|---|---|---|---|
| 1 | 产品等级 | 下拉选择（请选择） | 选项参考：A级 / B级 / C级 |
| 2 | 创建时间 | 日期范围选择器 | `开始日期 - 结束日期` |
| 3 | 搜索 | 主按钮（实心主色 + 放大镜图标） | 触发查询 |
| 4 | 重置 | 默认按钮（带重置图标） | 清空所有搜索条件并重新查询 |
| 5 | 新增 | 主色描边/浅色底按钮（带 + 图标） | 跳新增页或弹新增对话框（可先只做入口） |

## 4. ② 列表卡片

### 4.1 批量操作按钮（卡片顶部左侧）

| 按钮 | 样式 | 行为 |
|---|---|---|
| 修改产品状态 | 实心主色（蓝） | 配合表格勾选行使用；未勾选时点击提示"请先选择商品" |
| 批量修改价格 | 实心红色（danger） | 同上；弹窗可先留占位 |

### 4.2 状态页签（按钮下方，页签式导航）

横向排列的文字页签，格式为 `名称(数量)`，当前页签主色 + 底部主色下划线：

```
出售中(2211) │ 仓库中(3) │ 已售罄(0) │ 回收站(1593)
```

- 切换页签即按状态过滤表格数据，并重置到第 1 页。
- 注意：参考系统还有「警戒库存(1)」页签，属于库存管理范畴，**本项目不做**。
- 括号内数量从接口返回（mock 阶段写死即可）。

### 4.3 数据表格

带斑马纹/悬停高亮，表头灰底（`#fafafa` 系），整表白色卡片内。

| 列 | 内容/组件 | 说明 |
|---|---|---|
| 多选框 | checkbox | 表头全选，配合批量按钮 |
| 展开列 | `>` 箭头图标 | 点击展开/收起行详情（见 4.4） |
| 商品编号 | 长数字文本，两行换行显示 | 如 `2074784708967186434` |
| 商品信息 | 左图右文：方形缩略图(约 50x50) + 商品名称 | 图加载失败给占位图 |
| 商品分类 | 文本，如 `柜 / 电视柜`、`几/推车 / 茶几` | 一级 / 二级 |
| 价格 | `¥ 12900.00` 格式，千分位非必须 | 右对齐或居中 |
| SPU编码 | 文本，如 `A-15-T-MKDSG` | |
| 供应商编码 | 文本，如 `A-15` | |
| 产品等级 | 彩色小标签（Tag） | A级=绿色系，B级=蓝色系，C级=橙色系 |
| 销售状态 | 开关（Switch），开=上架 | 切换时二次确认或提示，调用状态接口（mock 阶段仅前端切换+提示） |
| 创建时间 | `2026-07-08 17:16:37` | |
| 操作 | 文字按钮：`详情` `修改` `回收` | 详情/修改=主色文字，回收=红色文字 |

- 表格需要 loading 态、空数据态（"暂无数据"）。
- 列宽自适应，内容过多省略号；操作列固定右侧更佳。

### 4.4 行展开区（点击 `>` 展开）

展开行为一整行浅灰背景（`#fafafa` 系）的补充信息区，label 加粗、值为小标签（Tag），多列分布：

```
发货地区: [华东]        预计生产日期: （可为空）        产品等级: [A级]
```

- 展开区字段可以按项目实际字段调整，但保留"label + 标签值、横向多列、浅灰底"的呈现形式。
- 同一行再次点击箭头收起；展开图标由 `>` 变为 `v`。

### 4.5 分页（表格右下方）

完整分页组件，包含：总条数、每页条数下拉（10条/页）、页码、省略页、末页码、跳转输入框：

```
共 2211 条   10条/页 ▾   < 1 2 3 4 5 6 … 222 >   前往 [1] 页
```

- 切换页码/每页条数时携带当前搜索条件与状态页签重新查询。

## 7. 交互行为清单（验收用）

1. 进入页面默认选中「出售中」页签并加载第 1 页数据。
2. 输入搜索条件 → 点「搜索」按条件查询；点「重置」清空条件并恢复默认查询。
3. 切换状态页签 → 表格数据与总数同步变化，页码回到 1。
4. 勾选多行 → 「修改产品状态」「批量修改价格」可用（功能可先弹占位提示）；不勾选点击 → 提示"请先选择商品"。
5. 点击行首 `>` → 展开补充信息行；再点收起。
6. 切换「销售状态」开关 → 出现状态变更提示（真实接口后接）。
7. 「详情 / 修改 / 回收」：详情弹窗或跳详情页（可先占位）；回收需二次确认，确认后该行从当前列表移除（mock 阶段前端移除 + 提示）。
8. 分页：切页码、切每页条数、输入"前往 x 页"均正常刷新表格。
9. 新增按钮有入口（页面/弹窗可先占位）。

## 8. 明确不做（范围控制）

- ❌ 库存管理：警戒库存页签、库存预警、库存编辑、库存列均不实现。
- ❌ 新增/编辑商品的完整表单（本次只做列表页，入口留好即可）。
- ❌ 商品回收站的还原/彻底删除逻辑（列表过滤展示即可）。

## 9. 建议实施顺序

1. 建路由 + 菜单（商城系统 → 商品中心 → 商品列表）。
2. 页面骨架：搜索卡片 + 列表卡片 + 分页静态布局。
3. 表格 + mock 数据渲染（含等级标签、状态开关、行展开）。
4. 搜索/重置/页签切换/分页联动逻辑。
5. 封装 `api/mall/product/spu.ts` 接口层（list、状态统计、修改状态、回收），先返回 mock。
6. 对接真实接口，联调。
